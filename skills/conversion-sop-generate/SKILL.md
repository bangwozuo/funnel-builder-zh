# 转化 SOP 生成

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_04_sk02` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 引流转化师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中（SOP 骨架可泛化到其他员工的培育场景） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

生成 7 天/30 天培育触达剧本

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `goal` | string | ✅ | 要达成什么 |

## 输出规格

流程与方案设计

- `steps`：可执行的步骤
- `scripts`：执行时可直接使用的话术或模板
- `risks`：可能出问题的地方与应对

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 分步流程

| 阶段 | 动作 | 负责人 | 产出物 | 时间点 |
|---|---|---|---|---|
| D0 欢迎 | 新粉添加后 10 分钟内发送欢迎语+电子书领取链接，打标签「引流来源：自律电子书」 | 运营 | 欢迎语已发送名单、标签覆盖记录 | 添加当日 |
| D1 破冰 | 助教逐条查看新粉朋友圈/入群情况，对开口新粉按话术 S1 回应；未开口者不发私聊，仅朋友圈互动 | 社群助教 | 开口新粉台账（记录需求关键词） | 第 1 天 20:00 前 |
| D2 邀请入群 | 批量邀请新粉进「启蒙妈妈交流群」，进群后发欢迎话术 S2 与群规 | 运营 | 入群率统计表 | 第 2 天 |
| D3 价值触达 | 群内做「3 个睡前启蒙小游戏」文字分享，配合朋友圈发布学员常见问题整理（不引用未提供的数据） | 社群助教 | 分享内容存档、朋友圈截图 | 第 3 天 |
| D5 需求确认 | 对 D1 台账中提及「孩子坐不住/磨蹭」等关键词的新粉发私聊话术 S3，询问具体困扰并推荐体验课匹配点 | 社群助教 | 私聊记录、高意向名单 | 第 5 天 |
| D6 意向促成 | 向高意向名单发送体验课报名话术 S4 + 50 元新人券（券总成本 ≤1000 元预算内，按名单分批发） | 运营 | 发券记录、报名链接点击统计 | 第 6 天 |
| D7 收尾 | 未报名者发最后提醒话术 S5（券到期提醒），已报名者进体验课群并通知开课时间 | 运营+助教 | 付款转化率统计（目标 ≥5%，即 200 人中 ≥10 单） | 第 7 天 |

## 配套话术/模板

S1 开口回应：「妈妈你好呀，看到你领取了《自律孩子养成电子书》～我是启蒙助教 XX。方便说下你家宝贝几岁了吗？我可以帮你挑电子书里最适合你娃年龄的那部分内容。」

S2 入群欢迎：「欢迎 XX 妈妈！咱们群每晚 8 点会分享一个在家就能做的启蒙小游戏，置顶群公告里有《3 个睡前启蒙小游戏》可以先带娃玩起来，有问题随时@我～」

S3 需求确认私聊：「上次听你提到孩子（复述用户原话关键词），电子书第 X 章正好讲了对应的处理思路。另外我们有节 399 元的体验课，会把这套方法拆成可以每天跟着做的练习，要不要我把课程安排发你看下？」

S4 报名促成：「体验课是 6 节录播+2 次助教答疑，这周报名可以用 50 元新人券，到手 349 元。我把报名链接发你，孩子在哪天方便上课，我帮你备注对应批次的答疑时间～」

S5 到期提醒：「XX 妈妈，你的 50 元新人券今晚 24 点到期啦，还没用的话记得今天报名哦，逾期就要按原价 399 元了。有疑问直接回我消息～」

（以上话术为 AI 生成草稿，使用前需人工确认；不承诺任何效果数据。）

## 风险与预案

1. 新粉添加后不回复：不动用频繁私聊，改为朋友圈+群内容持续触达，避免被删；D3、D5 各一次自然触达即可。
2. 券成本超预算：50 元券分批发放，先发 D6 名单前 60 人，超出部分改发 30 元券，保证月成本 ≤1000 元。
3. 助教人力不足导致私聊积压：D5 触达按「D1 台账关键词命中者优先」排序，当天未覆盖的顺延至 D6 上午，不群发模板轰炸。
4. 转化率未达 5%：D7 结束后复盘开口率、入群率、私聊回复率三个中间指标，定位漏斗断点后再调话术，不盲目加推。

> 注：以上为 AI 生成内容，执行前需人工确认排期与话术。
