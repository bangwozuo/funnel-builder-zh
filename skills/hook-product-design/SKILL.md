# 钩子产品设计

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_04_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 引流转化师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中（1 选题策划师可做钩子类选题） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

设计资料包/清单/测评类引流钩子

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `topic` | string | ✅ | 要围绕什么内容做钩子 |

## 输出规格

钩子与创意生成

- `hooks`：8-10 条可直接使用的钩子
- `angles`：每类角度的适用场景
- `avoid`：容易失效或违规的表达方式

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "topic": "零基础小红书运营起步资源包（含账号定位模板 1 份、爆款标题公式 20 条、周更发布排期表 1 份）",
  "audience": "22-30 岁想做副业的小红书新手博主，粉丝量 500 以下，发过笔记但数据不稳定",
  "platform": "小红书：偏好干货清单型笔记，标题 20 字以内，封面大字报风格，避免绝对化用语与数据承诺"
}

```

**输出**：

```markdown
<!-- AI 生成内容 · 人工复核后方可对外使用 -->

## 钩子候选

1. 发了 3 个月笔记没起色？可能你缺的是这张账号定位表
2. 小红书新手别急着发笔记，先把这份定位模板填完
3. 20 条标题公式，直接套着改，新手也能写出想点开的封面
4. 一周发几条、几点发？这张排期表帮你把更新节奏定下来
5. 做副业博主第 1 步：花 10 分钟填完这份起步清单
6. 粉丝 500 以下必存：账号定位模板+标题公式+排期表一次拿齐
7. 笔记数据不稳定，先自查这 3 个位置有没有填对
8. 别人更新有节奏，你更新靠心情，差的就是这张表
9. 从 0 开始做小红书，这份清单帮你把第一步走稳
10. 评论区扣「起步」，把这份资源包安排给你

## 切入角度

| 角度 | 适用场景 | 示例钩子 |
|---|---|---|
| 痛点反思 | 目标人群已尝试过但受挫，共鸣类笔记封面 | 1、7（发了没起色/数据不稳定） |
| 工具清单 | 干货收藏向笔记，配合大字报封面列出包内三件内容 | 5、6、9（清单一次拿齐） |
| 行动指令 | 引导评论互动、拉高笔记热度时使用 | 3、10（直接套用/评论区扣字） |
| 节奏规划 | 目标人群更新不稳定、需要方法感时使用 | 4、8（排期表/节奏对比） |
| 顺序纠偏 | 强调「先定位再发笔记」的正确顺序，制造认知差 | 2（别急着发笔记） |

## 不建议的表达

1. 不使用「最好」「第一」「100%」「月涨万粉」等极限词与效果承诺，易违反《广告法》及平台规则。
2. 不写「不涨粉你来找我」类兜底承诺，属无法兑现的效果保证。
3. 不用「免费送」堆叠诱导关键词刷屏，易被平台判定营销限流；领取动作用「扣字领取」等自然表达。
4. 不冒充「官方运营」「内部数据」等身份或信源。

> 注：以上为 AI 生成内容，发布前需人工确认合规。


```
