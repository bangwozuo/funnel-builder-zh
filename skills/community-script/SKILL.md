# 社群话术

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_04_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 引流转化师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 高：3 评论区回复话术同源引擎 |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

社群活跃/成交/唤醒话术

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `question` | string | ✅ | 用户的问题原文 |

## 输出规格

应答与话术

- `reply`：可直接使用的回复内容
- `intent`：识别到的用户意图与情绪状态
- `escalate`：是否需要转人工及原因；涉及金额/赔付的必须升级

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "question": "亲爱的，我上周买了你们的课程，说好的配套模板包到现在还没收到，已经第8天了，什么时候能发我？",
  "context": "用户「小雨」在微信群「小红书成长实验室3群」提问。订单号 DD20260930123，2026-09-30 购买《小红书零基础运营课》（¥299），购买时承诺「24小时内发放配套模板包」，当前为购课第 8 天，订单显示已支付但履约记录为空。",
  "persona": "社群助教人设：专业温和，称呼用户为「亲爱的」；可承诺范围：道歉、补发履约材料、承诺 24 小时内补发；不可承诺：价格减免、赔付金额、平台规则解释（此类需转人工）。"
}

```

**输出**：

```markdown
<!-- AI 生成内容 · 人工复核后方可对外使用 -->

## 应答话术

亲爱的小雨，实在抱歉让你久等了！我刚在后台核对了你的订单（DD20260930123），确认模板包因系统同步问题没有成功发放，这是我们的疏漏，跟你说声对不起。我这边已经为你手动登记补发，会在 24 小时内把《小红书零基础运营课》全套配套模板包发到你的微信，发出来第一时间告诉你。麻烦你确认一下现在这个微信号就是购课微信，方便我直接补发，谢谢你的耐心等待～

## 意图与情绪

| 项 | 内容 |
|----|------|
| 用户意图 | 催促补发已购课程的履约材料（配套模板包） |
| 情绪状态 | 不满但有耐心，属合理催促，未表达退款或投诉意图 |
| 关键事实 | 订单 DD20260930123 已支付，承诺 24 小时发放，实际第 8 天未收到，履约记录为空 |
| 责任归属 | 我方履约缺失，应道歉并立即补救 |

## 升级判断

1. 本次不涉及金额/赔付诉求，用户仅要求补发，属社群助教授权范围（可承诺 24 小时内补发），无需升级人工。
2. 若用户后续提出退款、赔偿或情绪升级为投诉，立即转人工客服处理。

> 注：以上为 AI 生成内容，对外发送前需人工确认。


```
