## 能力描述

按维度权重对粉丝记录逐条打分（0-100 分）并分层，输出**可复算的打标结果**：

1. **三条确定性公式**——互动活跃度 = min(100, 发言数×2)×0.6 + 响应率×40；付费行为 = 未付费 10 分，已付费 min(100, 50 + 单数×15 + min(30, 金额÷100))；影响力 = min(100, 10 + 分享×10 + 转介绍×15)
2. **加权总分**——总分 = 互动×40% + 付费×40% + 影响力×20%，保留 1 位小数；权重合计必须等于 100%
3. **四层阈值**——80-100 关键户 / 60-79 活跃户 / 40-59 潜力户 / 0-39 沉默户，每层配可执行动作（谁、做什么、14 天内）
4. **复核留痕**——每条评分附证据（发言条数/响应率/付费单数与金额），样本 <30 条时提示占比波动（每条 ≥3.3%）

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `records` | string | ✅ | 每行一条：`ID\|昵称\|互动数据\|付费数据\|影响力数据`，5-200 条 |
| `dimensions` | string | ⬜ | 维度与权重（百分比合计 100%），缺省用 40%/40%/20% |
| `thresholds` | string | ⬜ | 分层阈值，缺省 80/60/40 |

## 输出规格

打分与分层

- `scores`：逐条给出各维度分与总分
- `segments`：各层数量与特征
- `assumption`：所用维度、权重与阈值的来源或假设

## 调用示例

**输入**（`examples/input.json`，妈妈群 8 条真实打标记录）：

```json
{
  "records": "F001|小林|近30天群发言45条，私聊响应8次中6次|近90天付费1单（399元体验课）|朋友圈分享3次，转介绍报名2人\nF002|阿真|…",
  "dimensions": "互动活跃度（权重40%）…付费行为（权重40%）…影响力（权重20%）…每维度0-100分。",
  "thresholds": "总分0-100：80-100为关键户，60-79为活跃户，40-59为潜力户，0-39为沉默户"
}
```

**输出**（脚本实跑，8 条 → 关键户 1 / 活跃户 1 / 潜力户 2 / 沉默户 4）：

| # | 对象 | 互动活跃度 | 付费行为 | 影响力 | 总分 | 分层 |
|---|---|---|---|---|---|---|
| 1 | 小林 | 84.0 | 69.0 | 70 | 75.2 | 活跃户 |
| 3 | 多多妈 | 2.4 | 100.0 | 10 | 43.0 | 潜力户 |
| 7 | 大圣妈 | 76.0 | 85.0 | 100 | 84.4 | 关键户 |
| 4 | 壳壳 | 0.0 | 10.0 | 10 | 6.0 | 沉默户 |

完整结果见 `examples/output.md` 与 `out/粉丝分层报告.md`。
