## 能力描述

添加→培育→成交各环节转化诊断，输出**可核对的漏斗诊断**：

1. **转化率重算**——各环节转化率 = 下游人数 ÷ 上游人数（脚本重算，保留 1 位小数），不采信原文自带百分比
2. **断点定位**——逐级转化率与上期对比，降幅最大的一级（百分点差）即漏斗断点，如 7 天私聊率 65.1%→60.0%（-5.1pp）
3. **环比与周度**——环节级环比（如新粉 +34.4%）与周度趋势表（新粉 260→210→190→160 递减 -38%）
4. **归因纪律**——活动与指标变化仅时间重合时表述为相关性推断，缺分渠道数据列入数据缺口

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | string | ✅ | 各维度、各周期的漏斗指标数据（CSV / JSON / 表格 / 带数字文本） |
| `context` | string | ⬜ | 同期发生的内容/活动/外部事件（异业活动、人员请假等） |

## 输出规格

归因诊断

- `conclusion`：一句话概括最重要的发现
- `drivers`：因素与影响方向、幅度
- `confidence`：本次分析的置信水平与理由
- `next_action`：可执行的行动建议

## 调用示例

**输入**（`examples/input.json`，2026-09 私域转化漏斗真实数据）：

```json
{
  "data": "私域转化漏斗 2026-09-01 至 09-30：新添加企业微信 820 人；添加后 7 天内发生私聊互动 492 人（60.0%）；体验课付款 74 人（9.0%）；体验课学员升级年课 11 人（14.9%）。8 月对比：新粉 610 人，7 天内私聊 397 人（65.1%）…",
  "context": "9 月上线两次《自律孩子养成电子书》异业引流活动，合计带来 410 名新粉；9 月中旬履约助教病假约 1 周…"
}
```

**输出**（脚本实跑：4 环节漏斗 + 周度趋势 + 环比）：

| 环节 | 本期人数 | 相对上环节 | 上期人数 | 上期相对上环节 |
|---|---|---|---|---|
| 新粉 | 820 | — | 610 | — |
| 7天私聊 | 492 | 60.0% | 397 | 65.1% |
| 体验课 | 74 | 15.0% | 61 | 15.4% |
| 年课 | 11 | 14.9% | 9 | 14.8% |

断点提示：「7天私聊」占新粉比例环比 -5.1pp（60.0% vs 65.1%）；周度新粉 260→210→190→160 递减。
完整结果见 `examples/output.md` 与 `out/转化漏斗分析报告.md`。
